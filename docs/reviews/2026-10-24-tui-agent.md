## Performance evidence

Command: `bun scripts/bench-tui-review.ts`. Local Bun version: 1.3.11. Each case ran once to warm up, followed by seven measurements; the table reports their median. These are CPU microbenchmarks, not end-to-end response times from a real model.

| Workload | Before the fix | After the corresponding fix |
| --- | ---: | ---: |
| Style slicing for 20,000 Markdown lines | 183.846 ms | 1.629 ms |
| Repainting 2,000 collapsed tool blocks | 8.288 ms | 0.649 ms |
| Repainting a 100,000-line plain response (control) | 1.617 ms | 1.789 ms |

The Markdown improvement comes from avoiding repeated prefix scans. The tool-block improvement comes from avoiding width calculations for offscreen content. The control received no targeted optimization; its small variation is not treated as evidence of a regression or improvement.
